# 视频号追投助手

这个 Tampermonkey 脚本在视频号标准订单列表中查找来源订单，支持逐单设置新订单名称和追投预算。提交后由用户手动支付。

## 安装与使用

1. 在 Tampermonkey 中新建脚本，或打开已安装的「视频号标准订单逐单加热助手」。
2. 将 [脚本](./视频号标准订单逐单加热助手.user.js) 的完整内容粘贴到编辑器并保存，然后刷新视频号订单列表。
3. 在助手中输入订单名称并扫描，核对来源订单、名称和预算后开始逐单处理。每一单的支付由用户在平台完成。

## 本地验证

在仓库根目录运行以下命令。测试使用模拟页面数据，验证来源订单定位、名称与预算、优惠券和支付结果核对。

```sh
node --check "视频号标准订单逐单加热助手.user.js"
node --test
```

## 版本

- `v0.2.3` 保存每笔来源订单所在页，优先在记录页及后续页查找，必要时回查前页。使用来源订单 ID 精确核对。

后续更新以仓库根目录的 `.user.js` 为准。更新脚本时同步修改 `@version`，通过测试后提交，并以相同版本号打标签。
