逐单加热助手兼容扫码和免验证支付：确认本轮订单并授权提交及支付后，平台要求扫码时等待用户扫码，显示“免验证提交”时直接提交付款；每单核对成功后继续下一单。按平台实际页面判断，不在本地记录当天首笔。

## 千川新旧 ROI 字段兼容

素材追投 Windows `v0.4.41` / 安卓 `v0.4.43`，调控 Windows `v0.1.18` / 安卓 `v0.1.23`：兼容账户逐步上线的「1小时净成交综合营销ROI」和「调控1小时净成交综合营销ROI」，继续支持旧的「综合营销ROI」「调控综合营销ROI」和「调控支付ROI」。

素材追投有 1 小时净成交列时优先按该列降序和阈值选素材，没有时使用旧列；排序、翻页、行读取及提交前复核使用同一列。执行记录和报告标明实际列名，本轮中途更换 ROI 列时暂停。只显示 24 小时净成交列时，不将其替代为 1 小时指标。

四类助手的 Windows、安卓版均已检查字段依赖：本次修改涉及追投和调控共 4 个脚本文件；定时调速没有 ROI 筛选，零消耗清理按综合成本判断，二者读取的字段不受 ROI 列更名影响，因此沿用原版。

## 调控助手：共用 ROI 阈值

Windows `v0.1.12` / 安卓 `v0.1.17` 的商品调控只需输入一个「调控 ROI 阈值」：自动按当前任务表显示的「调控综合营销ROI」或「调控支付ROI」判定；两列都显示时共用此阈值，保留原来任一已显示列低于阈值或为「—」即入选的规则，不相加、不取平均。未显示列不参与判断，综合成本和调控消耗必须均大于零；仍需先检查清单，再确认执行。

旧版两项阈值相同或只保存一项时自动继承；两项不同则留空，必须重新填写。

Windows `v0.1.17` / 安卓 `v0.1.22` 在「筛选条件」里新增独立按钮「低 ROI 删除（保留 0 消耗）」。锁定直播或商品计划后，点击该按钮，设置 ROI，再检查本页并确认执行。该入口只允许删除消耗确认大于 0 且符合低 ROI 条件的任务。原「本次操作」下拉框保留之前的规则：直播按调控状态和支付 ROI 筛选，商品原本就要求综合成本和调控消耗都大于 0。

## 视频号逐单加热助手名称库

名称库编辑区默认隐藏，点击「管理名称库」才展开。保存名称库、恢复清单、将当前清单加入库、扫描订单或开始执行后自动收起；收起设置或最小化助手时也会收起名称库，未保存的库编辑草稿在当前页面中保留。点击「从名称库恢复」将已保存的完整名称库填回当前清单，再点击「扫描订单」。当前清单可以临时删减，不会修改名称库。「管理名称库」中每行一个名称，可新增、删除或改名，点击「保存名称库」后生效；「当前清单加入名称库」只补充新名称，不用临时清单覆盖整个库。「补回内置名称」把最初内置的 20 个名称补入库编辑框，保存后生效。

首次升级会合并内置名称和本浏览器旧版已保存的默认名称，保留当前清单及进行中的队列。名称库保存在当前浏览器的油猴存储中，刷新或更新脚本后保留；自定义修改不会自动同步到 GitHub 或其他浏览器。新浏览器首次安装使用脚本内置名称。

## 视频号订单成本保障风险预警

独立油猴脚本 `v0.1.9`：临时应用平台“加热中”状态筛选，只扫描这些订单的分页，结束后按原先实际勾选项恢复筛选和页码；设置筛选后先收起状态菜单，再点击平台“筛选”，并等待列表稳定后核对状态；恢复原筛选时按原筛选状态验收，不再错误要求列表只能有在投订单。扫描期间显示进度条、当前页数和结果汇总。面板样式对齐标准订单逐单加热助手，可拖动标题栏并记住位置；默认停靠在加热助手左侧，侧边入口错开。ROI 支持同时设置上下限，或只设一个边界；沿用旧版低 ROI 阈值为新上限。输入范围变化时会立即重新筛选已扫描结果，并显示当前生效区间；扫描汇总显示 ROI 已读取和未读取数量。结果分为未超过赔付线、超过赔付线、暂无法判断三组；前两组各有批量停止入口，批量执行前展示订单编号确认并逐单复核，平台弹窗或状态未改变时暂停。对按元成交出价的订单，按当前消耗/直接成交订单数估算成交成本，并假设剩余投放表现不变，计算预算完成时的预计消耗/预期消耗；严格高于规则中的 120% 才标为趋势风险。它是趋势估算，不代表平台已确认赔付。

脚本读取列表显示的直接成交订单数，无法确认它与平台审核的有效成交数完全一致。300 元现金消耗、至少 2 次有效成交、控成本加热、未使用加速起量、支付方式、审核状态等资格需要人工核实；满足列表可见的消耗和成交数时也只标注为“部分门槛已到”。ROI 出价订单因平台预期消耗算法未能从订单页面确认，不套用成交出价公式，显示“无法可靠估算”。

对预测超过 120% 且直接成交 ROI 低于阈值的订单，可逐单打开详情并触发平台“停止加热”入口。触发前会二次确认，并重新核对订单编号、列表指标和详情页状态；平台若显示确认弹窗，由用户完成最终确认。脚本不使用“结束订单”菜单。扫描会恢复原状态筛选与页码，账户切换或订单数据变化会中止停止流程。

## 视频号逐单加热助手批量预算与出价

`v0.2.16` 起，扫描完成后，在结果上方的「批量修改」输入统一预算、投放目标和出价，点击「批量应用到已选订单」。预算留空可以只改目标与出价，选择「不修改目标与出价」可以只改预算。每单仍可单独编辑名称、预算、目标与出价；「恢复来源参数」还原名称和预算，并沿用来源目标与出价。填写了尚未应用的批量参数时，点击开始会提示先应用，防止忽略刚输入的设置。

| 统一投放目标 | 短视频订单 | 直播订单 | 助手允许的出价范围 |
| --- | --- | --- | --- |
| 成交（按元出价） | 商品成交数，单个用户转化出价 | 直播间成交，每个订单成交的出价 | 0.1～5000 元，最多两位小数 |
| ROI | 商品ROI，自定义ROI | 成交ROI | 0.5～50，最多两位小数 |

所有预算须为 100 的整数倍且不超过 300000 元。普通短视频预算至少 100 元，切换商品 ROI 后至少 300 元；直播预算至少 200 元。整批校验通过后一次保存，任一订单不合法时整批不应用。最低直接成交 ROI 仍是扫描筛选条件，与本次新增的下单出价分别设置。

点击开始后锁定每单设置，助手逐单选择目标、选择控成本加热并填写出价，再设置预算，提交前核对来源、名称、目标、出价、预算与优惠券后的支付金额。目标切换会重置部分平台控件，因此必须重新读取并核对；找不到对应选项、输入范围不符或平台显示错误时暂停。执行中不能修改已锁定的参数，已提交订单只核对结果，继续保留防重复提交保护。
